# Alexandra & Dalton — GitHub Pages package

The docs folder contains the complete static website: all 10 pages, styles, scripts, optimized gallery photos, other site images, local fonts, and calendar downloads. It does not need Node or the localhost preview server.

## Publish

1. Copy this folder's contents into your GitHub repository, keeping the docs folder intact.
2. Commit and push the files.
3. In the repository, open Settings → Pages.
4. Choose Deploy from a branch, select your branch (usually main), and select /docs. Save.

GitHub instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Addresses

Pages use /home/, /schedule/, /venues/, /lodging/, /travel/, /wedding-party/, /gallery/, /registry/, /faqs/, and /rsvp/. The final slash is normal for GitHub Pages directory URLs. Existing .html URLs and the site root redirect to the corresponding clean page. Links and assets work beneath a repository prefix or at a custom-domain root.

This is a snapshot of the local wedding site. Later local edits must be included in a refreshed package before publishing. RSVP and Registry retain their current coming-soon messages. Wedding-party portraits and biographies remain placeholders. No RSVP collection backend is included.
